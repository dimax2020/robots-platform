## Термины и сокращения

Первые одиннадцать терминов перенесены из ТЗ, остальные добавлены по п. 3.3 дополнений к ТЗ.

| Термин | Определение |
|---|---|
| SKU | Единица номенклатуры товара |
| CAPEX | Капитальные затраты на приобретение и внедрение решения |
| OPEX | Операционные затраты на эксплуатацию решения |
| ROI | Отношение полученного экономического эффекта к инвестициям |
| TCO | Совокупная стоимость владения решением |
| WMS | Система управления складом |
| ERP | Система планирования ресурсов предприятия |
| API | Программный интерфейс обмена данными |
| MVP | Минимально жизнеспособная версия продукта |
| БАС | Беспилотная авиационная система |
| БРС | Беспилотная роботизированная система |
| СУБД | Система управления базами данных. В решении PostgreSQL 16 |
| AMR | Autonomous Mobile Robot, автономный мобильный робот |
| FMR | Forklift Mobile Robot, автономный вилочный погрузчик или штабелёр |
| RaaS | Robots as a Service, «роботы как услуга» (аренда) |
| DES | Discrete-Event Simulation, дискретно-событийная имитация. В решении имитация идёт с постоянным шагом 0,5 с (раздел 6) |
| SLAM | Simultaneous Localization and Mapping, одновременная локализация и построение карты. В решении не используется, применяется в описаниях навигации роботов |
| УГТ (TRL) | Уровень готовности технологии, шкала 1–9 |
| ФОТ | Фонд оплаты труда |
| PBP | Простой срок окупаемости (payback period) |
| Процесс | Задача, которую выполняет робот на объекте: «Перевозка паллет», «Уборка помещений» и т. п. Справочник содержит 65 процессов |
| Тип решения | Класс роботов внутри каталога: AMR, FMR, робот-уборщик, манипулятор и др. Справочник содержит 85 типов |
| Вердикт | Результат подбора для пары «робот — процесс»: «Подходит», «С условием», «Уточнить», «Не подходит» |
| Демо-проект | Опубликованный администратором проект с данными организатора. Открывается всем, редактируется только администратором |
