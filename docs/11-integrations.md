# Раздел 11. Интеграции

*Закрывает пп. 3.8.1–3.8.3 ТЗ. Интеграции описаны, не реализованы.*

## 11.1. Что есть сейчас

| Что | Как |
|---|---|
| REST API платформы | 89 методов, Swagger UI, описание в [api.md](api.md) |
| Импорт данных площадки | Файл CSV/Excel по шаблону на шаге «Параметры» |
| Импорт каталога | `POST /admin/imports` (CSV), парсеры сайтов |
| Экспорт результатов | Печать в PDF, Excel (.xls, SpreadsheetML), CSV, PNG схемы |

Доступ к API по cookie-сессии; ключей и токенов для внешних систем нет.

## 11.2. Планируемые интеграции

| Система | Что передавать | Способ | Статус |
|---|---|---|---|
| WMS | Объём потоков, число паллетомест, режим работы → параметры площадки | REST: `PATCH /projects/{id}` от сервисного пользователя | Описано |
| ERP / 1С | Численность и зарплаты ролей → ФОТ | Тот же метод либо выгрузка в CSV | Описано |
| Мониторинг парка | Фактическая загрузка → сверка с имитацией | Не проработано | План |
| Маркетплейсы поставщиков | Цены и наличие → карточки | Парсеры, `POST /admin/imports` | План |

## 11.3. Что нужно для реализации

1. Сервисные токены вместо cookie.
2. Публичная часть API отдельно от админской.
3. Сохранение расчёта снимком, чтобы внешняя система получала стабильный результат.
