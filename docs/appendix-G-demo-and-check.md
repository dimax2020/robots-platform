## Расчёт на 17 роботах без интерфейса

Парк: RoboCV ×5 (буксировка), AI Stock Counter 12M ×2 (инвентаризация), Ronavi H1500 ×5 (перевозка паллет), DMR Carrier P ×5 (размещение на ярусах). Выбор берётся из `best_product_id` подбора.

```python
import json, urllib.request as u
B = "http://localhost/platform/api/v1"
def call(method, path, body=None):
    req = u.Request(B + path, method=method, headers={"content-type": "application/json"},
                    data=None if body is None else json.dumps(body).encode())
    return json.load(u.urlopen(req))

site = call("GET", "/projects/demo-warehouse")["site"]
groups = {g["process_code"]: g for g in call("POST", "/projects/demo-warehouse/match", {"site": site})["groups"]}
codes = ["pallet_transport", "cart_towing", "warehouse_inventory", "rack_placement"]
picks = {c: groups[c]["best_product_id"] for c in codes}
e = call("POST", "/projects/demo-warehouse/economy", {"site": site, "picks": picks, "choices": {}})
for s in e["scenarios"]:
    print(s["key"], s["capex"]["value"], s["opex"]["value"], s["effect"]["value"], s["payback"]["value"])
```

Ожидаемый вывод: `purchase 79547488.0 12908244.8 115052315.2 0.6914…`, `raas 18602046.0 18705244.8 109255315.2 0.1702…`.

Расчёт по шагам с формулами: раздел 5.7. Важно передавать `site` явно: пустое тело подбора считается площадкой без параметров, и правила не срабатывают.
