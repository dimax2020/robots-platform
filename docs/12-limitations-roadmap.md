# Раздел 12. Известные ограничения и план развития

*Закрывает п. 6.9 ТЗ.*

## 12.1. Ограничения

| № | Область | Ограничение | Влияние |
|---|---|---|---|
| 1 | Экономика | Экономия ФОТ по всему парку = 63 % от ФОТ площадки, не зависит от числа и состава роботов; по процессу ФОТ делится поровну (раздел 5.8) | Окупаемость завышена при малом парке и отсутствует при очень большом |
| 2 | Подбор | «Лучший» робот выбирается по одной характеристике (обычно максимум грузоподъёмности), не по цене; баллов и весов нет | По умолчанию в парк попадают дорогие модели |
| 3 | Данные | Грузоподъёмность есть у 31 % карточек, время работы у 27 %, скорость у 13 % | Большинство пар получает вердикт «Уточнить» |
| 4 | Данные | Фильтры настроены у 19 из 65 процессов; 45 процессов без правил и без формул количества | Для них роботы получают «Подходит» без проверки |
| 5 | Объекты | Экономика, what-if, визуализация и отчёт доступны только для склада | Аэропорт и медучреждение: три шага |
| 6 | Демо | У демо-проектов нет сохранённой схемы | Визуализация на демо пустая |
| 7 | Демо | Название демо-склада «12 000 м²», а в параметрах площадь 20 000 м² | Нужно привести в соответствие |
| 8 | Версии | Расчёты не сохраняются, версий каталога и модели нет | Результат меняется вместе с каталогом |
| 9 | Аренда | Нет срока договора, выкупа, платы за использование | RaaS = фиксированный процент цены |
| 10 | Экономика | Нет дисконтирования, NPV, IRR; в TCO нет замены узлов; чувствительность только для покупки | Оценка грубая |
| 11 | Имитация | Роботы не объезжают друг друга, сетка 1 м, не влияет на экономику | Только проверка потока |
| 12 | Безопасность | Нет TLS, секрет сессии по умолчанию, пароли демо известны, порт БД открыт | Только для демонстрации |
| 13 | Нагрузка | Проверок на 50 одновременных пользователей и разрешения 1366×768 не проводилось | Не подтверждено |
| 14 | Регистрация | Нет саморегистрации, есть три демо-записи | |
| 15 | Тесты | 1 из 149 тестов падает (`test_classify_cleaner_and_forklift`) | На расчёты не влияет |
| 16 | Интеграции | WMS, ERP, 1С не подключены | Раздел 11 |
| 17 | Экспорт | «Excel» это SpreadsheetML (.xls), не .xlsx | Открывается в Excel с предупреждением |
| 18 | Сценарии | Страница `/projects/{id}/scenarios` — макет | Не используется в шагах |
| 19 | Чистая установка | Включены все 18 объектов, в проде 3 | Мастер проекта у проверяющего шире |

## 12.2. План развития

| Приоритет | Что сделать |
|---|---|
| 1 | Привязать долю замещения к выбранным роботам и охвату процессов |
| 1 | Выбор «лучшего» с учётом цены; при желании веса критериев |
| 1 | Схемы для демо-проектов, привести в порядок название и площадь демо-склада |
| 2 | Сохранение расчёта снимком и версии каталога |
| 2 | Экономика и визуализация для аэропорта и медучреждения |
| 2 | Заполнение ТТХ по каталогу, фильтры для остальных процессов |
| 2 | Обратная связь: результат имитации → число роботов в экономике |
| 3 | RaaS с условиями договора, NPV/IRR, чувствительность для аренды |
| 3 | TLS, секреты, регистрация, роли, токены для интеграций |
| 3 | Интеграции WMS/ERP, нагрузочные тесты, .xlsx |
